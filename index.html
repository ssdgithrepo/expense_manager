How it works
  1. Choose your vehicle.
  2. Press Start Trip — the app accumulates GPS distance automatically.
  3. If you stop moving, tracking auto-pauses; it resumes by itself the moment you move again.
  4. You can log fuel top-ups mid-trip and the totals update instantly.
  5. Stop to save the trip with its distance and fuel cost breakdown.

Settings
If the map stays blank after saving a key, it's almost always one of these — all fixed in Google Cloud Console:
  1. Billing not enabled on the project (required even for the free monthly credit).
  2. Maps JavaScript API and Places API not enabled for the project.
  3. The key has an HTTP-referrer restriction that doesn't include this page's address — if you're testing by double-clicking the file (a file:// address) or from a new hosting domain, either remove the restriction while testing or add that exact address to the allowed list.
  4. A typo or extra space pasted into the key field.
Once you grant location access, tracking starts on its own as soon as you start moving — no need to tap Start. If you go quiet for 20 minutes, the trip/walk is automatically saved so nothing is ever lost, even if you forget to press Stop.
